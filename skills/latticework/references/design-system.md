# Design system — Latticework (Notion-clean)

The reference implementation of every token below is the repo's `mockups.html`
(generated by `build_mockups.py`). When porting to SwiftUI, match these exactly.

## Typeface — Open Sans ONLY
- Family: **Open Sans** (web: Google Fonts; iOS: bundle the Open Sans `.ttf`
  weights and register via `UIAppFonts`, or use a close system fallback only if
  unavailable). Never add a second font family.
- Weights used: 300 (display), 400 (body), 500, 600 (UI / labels), 700 (titles).
  Italics: 300/400 for quotes.
- Hierarchy = weight + size + spacing, not multiple fonts.

### Type scale (pt sizes from the mockups)
| Role | Size | Weight | Notes |
|---|---|---|---|
| Page title (`.ttl`) | 27 | 700 | letter-spacing −0.03em, icon chip beside it |
| Display (model title, premium) | 30 / 19–26 | 300 | airy; letter-spacing −0.03em |
| Quote | 17–19 | 300 italic | line-height 1.55, the hero |
| Body (`.kp`) | 13.5 | 400 | line-height ~1.62, color `#4B4943` |
| List item title | 14.5 | 600 | |
| Label / kicker (`.kv`,`.sec`) | 11 | 600–700 | UPPERCASE, letter-spacing .07em, color faint |
| Attribution | 12 | 600 | color faint |
| Tab label | 10 | 600 | |
Numbers use tabular figures (`font-variant-numeric: tabular-nums`).

## Color tokens
| Token | Hex / value | Use |
|---|---|---|
| `page` | `#F7F6F3` | app canvas (warm off-white) |
| `bg` | `#FFFFFF` | surfaces / blocks |
| `ink` | `#37352F` | primary text, primary button, active tab |
| `ink2` | `#787774` | secondary text |
| `faint` | `#9B9A97` | tertiary / labels / inactive tab |
| `line` | `rgba(55,53,47,.09)` | hairline borders |
| `line2` | `rgba(55,53,47,.15)` | stronger hairline / option borders |
| `tag` | `#F1F0EE` | pill / chip background |
| `green` | `#448361` | success / reviewed / correct |
| `red` | `#C4554D` | incorrect |
One ink accent for primary actions. Color is rare and meaningful — no decorative
palettes, no gradients-as-decoration, no purple/blue "AI" gradients.

## Surfaces — flat "blocks", not cards
- `background: bg; border: 1px solid line; border-radius: 12px; padding: 22px;`
- Near-zero shadow. Tinted hover/press only (`rgba(55,53,47,.04)`).
- A `.tint` variant uses `#FBFBFA`. A `.premium`/emphasis variant uses `line2`.
- **No nested cards**, no box-in-box, no heavy elevation.

## Spacing & rhythm
- Generous. Block padding 22px; block-to-block gap 16px; section labels with
  ~26px top margin; body line-height ~1.6.
- Calm over dense. Let screens breathe.

## Components
- **Primary button:** solid `ink`, white text, ~9px radius, weight 600, optional
  leading bespoke icon. Ghost variant = transparent + `line2` border + `ink2` text.
- **Pill / tag:** `tag` background, 6px radius, 12px/600, with a 13px bespoke icon.
- **List rows:** hairline divider between items, bespoke discipline glyph in a
  30px `tag` chip, title 14.5/600 + faint subtitle.
- **Streak ring:** monochrome `conic-gradient(ink … , #E8E7E3 …)` with a white
  inner disc and tabular number.
- **Tab bar:** hairline top border, blurred translucent white, 5 tabs; active =
  ink, inactive = faint.
- **Title chip (`.glyph`):** 34px rounded square, 1px `line2` border, holds a 19px
  bespoke icon beside the page title.

## SwiftUI mapping hints
- Tokens → a `Theme` enum / `Color` asset set (light + dark).
- Blocks → a reusable `Block` container view (padding, hairline `overlay` stroke,
  12px `RoundedRectangle`).
- Quote → Open Sans light italic `Text`.
- Icons → a single `Icon` view that renders the bespoke `Path` set (see icons.md),
  never SF Symbols for brand glyphs.
- Respect Dynamic Type and provide a full dark-mode palette.
